# Исправления в `OrderTotal.php`

1. В `subtotal()` цена приводилась к `int`, поэтому копейки отбрасывались и итог заказа становился меньше фактического. Теперь умножается исходное значение `float`.
2. Для суммы с уже включённым НДС применялась формула `total × 20 / 100`, которая начисляет НДС сверху. Правильная доля НДС 20% внутри цены — `total × 20 / 120`.
3. В `calculate()` НДС вычислялся от суммы до скидки, хотя скидка уменьшает и итоговую сумму НДС. Расчёт теперь получает `total` после применения скидки.
